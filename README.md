# Rahul's India

A synthetic control counterfactual for India, 2014–2026, rendered as an editorial data site.

    CONGRESS India  actual pre-2014        (the estimation window)
    RAHUL India     synthetic 2014+        (what 35 comparator economies predict)
    MODI India      actual 2014+           (what happened)

## Deploying

Pushed to `main`, GitHub Actions builds and publishes to GitHub Pages
(`.github/workflows/deploy.yml`). **Repo Settings → Pages → Source must be set to
"GitHub Actions"**, not "Deploy from a branch" — a branch deploy serves the raw
source, and the browser cannot execute `src/main.tsx`, so the page renders blank.

The site lives under a sub-path, which two settings depend on:

    vite.config.ts   base: '/rahulsindia/'      asset URLs
    src/App.tsx      basename={BASE_URL}        router paths

Both read from the same value, and `base` applies to production builds only so
`npm run dev` still serves from `/`. GitHub Pages has no SPA fallback, so the build
also writes `dist/404.html` as a copy of `index.html` — without it a deep link like
`/indicator/43` is a hard 404 on reload or share.

## Run

    npm install
    npm run dev        # http://localhost:5173

## Hero image

Save the photograph to `public/img/hero.jpg` (16:9, ~1600×900). Until then the hero
shows a labelled placeholder. Note that press photographs are usually licensed —

### Indicator 37 — corrected

"Households covered by health insurance" was originally proxied by hospital beds per
1,000, which was wrong twice over: beds measure infrastructure supply rather than
financial coverage, and the WDI series for India is a smooth interpolated line that
any counterfactual would fit trivially. Its post window also closed in 2017, before
PM-JAY launched.

It is now proxied by **catastrophic health spending** (share of population spending
>10% of household budget on health) — the outcome health coverage is designed to
produce, 2003–2022, 17 donors.

    old  hospital beds per 1,000     gap  -5%   p=0.85   RAHUL AHEAD
    new  catastrophic health spend   gap -50%   p=0.056  MODI AHEAD   rank 1/18

Two related measures are carried on that indicator's detail page: government share of
health spending (+27%, but rank 18/36, p=0.50 — not distinguishable from peers) and
population impoverished by health spending (-14%).

## Design

High-End Editorial. Playfair Display (headers) / Georgia (body) / Plus Jakarta Sans (UI)
/ JetBrains Mono (figures). Light theme only.

Party palette, two shades each — the darker for text (WCAG AAA on paper), the
lighter for chart strokes and fills (WCAG 1.4.11, >= 3:1):

    rahul     #1D5FA8  blue    6.18:1   synthetic line (dashed)
    rahulInk  #14457C          9.26:1   text, links, focus rings
    modi      #D2691E  orange  3.48:1   actual line (solid)
    modiInk   #803A07          7.96:1   text

Colour is never the only cue: the synthetic line is dashed, the actual solid, and
every chart and card carries a written verdict badge.

## Verdict badge

Every one of the 50 carries a verdict, direction-aware (lower is better for mortality,
poverty, out-of-pocket spend, diesel use, turnaround time, import dependence and rank
series).

    MODI AHEAD   58
    RAHUL AHEAD   3     open defecation, rural sanitation, CO2 per capita
    NO DATA       1     net secondary enrolment (India has one observation)

                        indicators   Modi ahead   measured   significant
    original set                50           48         12             4
    out-of-sample               12           10          8             1

**The two bases are not equivalent, and the UI says so on every page:**

    tiers 1-2  "vs synthetic counterfactual"   actual path vs the estimated donor path
    tier 3     "2014 vs latest observed"       India against its own past, no counterfactual
    tier 3*    "rank N of M peers"             India against real comparator countries (#8)

A tier-3 verdict answers "did this improve since 2014?", not "did it improve more than it
would have anyway?" — a materially weaker claim. Tier-2 verdicts rest on a counterfactual
that does not fit (pre-2014 RMSPE above 15%). Only the 4 significant tier-1 results carry
statistical weight.

### Observed-verdict rules

Baseline is 2014, falling back to 2010 where 2014 is unavailable. The latest value prefers
the highest-quality late observation (exact > nearest > administrative), which matters:

    #20 railway electrification   the 2026 figure is "99% of broad-gauge", a different
                                  unit from route-km — excluded, 2024 (63,456 km) used
    #15 NH construction speed     the 2026 figure is partial-year; 2024 exact (33.83) used
    #21 railway diesel            lower is better, though the unit string does not say so
    #36 extreme poverty           no 2014 observation; 2010 (16.2) used as baseline

## Out-of-sample test

Twelve standard development indicators — HDI components, SDG headline, WDI core — run
through the identical pipeline: same 36-country pool, same nested V-search, same
permutation test. None were selected for this comparison.

    Unemployment rate               0.9%      7.81      4.17   -46.6%    1/36  0.028 *  MODI
    CO2 emissions per capita        3.6%      1.91      2.17   +13.5%    7/36  0.194    RAHUL
    Life expectancy at birth        0.4%     71.88     72.23    +0.5%    9/36  0.250    MODI
    Access to electricity           2.8%     98.96     99.90    +0.9%    7/19  0.368    MODI

The direction pattern replicates (7 of 8 favour Modi). The significance pattern largely
does not: 1 of 8 clears p <= 0.10, against 4 of 12 in the original set — a 12% hit rate
versus 33%.

**Discount the one significant result.** Unemployment's counterfactual is 60% Nepal, and
these are ILO *modelled* estimates, not measured. India's own PLFS series shows a
different level and turning point.

**Four could not be fitted, and they are not a random four:**

    Adult literacy rate         India has 13 observations; no country has a 10-yr pre-2014 block
    Net secondary enrolment     India has 1 observation (2013)
    Income inequality (Gini)    India has 6 observations, 1987-2022
    Child stunting              India has 10 observations; 1 country has a usable block

Literacy, enrolment, inequality and stunting are where India's development record is most
contested, and all four are survey-based — precisely the kind the method cannot touch. The
indicators that survive are those with dense annual administrative or modelled series. Any
tally built this way inherits that selection.

### Indicator 8 — UPI replaced by digital transactions

UPI transaction volume has no cross-country analogue, and the mobile-subscriptions proxy
standing in for it fitted at 22.3% — uninterpretable. Replaced with **total cashless
payment volume per person** from the BIS CPMI Red Book (cards, e-money, credit transfers,
direct debits and fast payments, UPI included).

    source   BIS CPMI, https://stats.bis.org/api/v1/data/WS_CPMI_CASHLESS
    coverage 8 of the donor pool (ARG BRA CHN IDN IND MEX TUR ZAF), 2012-2024
    India    2.81 -> 143.52 transactions per person per year (2013 -> 2024)

It still cannot reach tier 1: CPMI begins in 2012, leaving **two** pre-treatment years.
A two-point pre-period has zero degrees of freedom — any donor mix fits it exactly, and
nothing can be validated. So the indicator sits in tier 3 with a `peers` basis, showing
India directly against the seven other reporting countries:

    1 India 51.1x   2 China 21.1x   3 Indonesia 15.4x   4 Argentina 9.4x
    5 Türkiye 6.1x  6 Brazil 5.3x   7 Mexico 4.7x       8 South Africa 2.8x

India ranks first on per-capita growth. That is a real cross-country comparison — stronger
than tier 3's usual "India vs its own past" — but it is not a counterfactual, and every
one of these countries also built instant-payment rails over the same period.

### Energy indicators — corrected

Both OWID grapher series (`installed-solar-pv-capacity`,
`cumulative-installed-wind-energy-capacity-gigawatts`) are already in **GW**. An earlier
MW→GW conversion on solar divided it by 1,000, reading India's 2024 capacity as 0.10 GW
instead of 97.6 GW. Removed.

Both were then re-fitted per capita, since absolute capacity is not comparable across a
pool containing China (442 GW) and Jordan (0.6 GW). Per-capita improved wind's pre-2014
fit from 50% to 29% — still uninterpretable, and India ranks **last of 13** on placebo
fit, so no donor combination tracks its path. Solar has no balanced pre-2013 window at
all: capacity is near zero across the whole pool.

Both moved to tier 3, where their observed figures stand without a counterfactual:

    solar   2.82 GW (2014) -> 164.59 GW (2026)
    wind   21.04 GW (2014) ->  58.14 GW (2026)

## Structure

    src/lib/          data loading, types, number formatting
    src/components/   Chart, GapChart, Card, ObservedCard, Verdict, Carousel
    src/pages/        Home, Detail, Observed

All 50 indicators appear in three carousels, grouped by what the method can establish:

    1  Measured                      20   counterfactual estimated and placebo-tested
    2  Estimated, not interpretable   8   pre-2014 fit too poor to call
    3  No counterfactual possible    34   no counterfactual; observed India, or peer comparison

62 indicators from two sets:

    original set   50   supplied for this comparison
    out-of-sample  12   standard development measures, none selected for this comparison

Group 3 uses `ObservedCard` / the `Observed` page: the 2010 / 2014 / 2024 / 2026 figures
from the source JSON, with each observation's status (exact, nearest, legacy proxy,
administrative) spelled out. No synthetic path is drawn for them.

`Carousel` is generic over item type. Each rail loads 5 and reveals the next 5 as the
reader approaches the end, via IntersectionObserver with a scroll-position fallback
(observer callbacks are suspended in some environments, e.g. background tabs).

## Caveat carried through the UI

The counterfactual is "India without the 2014 structural break", estimated from
comparator countries. It is not a forecast of any individual's policy programme.
